# UFP0007-M01123966
Option B-Lab equipment Loans
This program will manage recording equipment in the lab, lend equipment to students and record returned equipment

How to run
1.Open the project folder in your code editor 
2.Locate and open the main.py file
3.Make sure Python is installed on your computer
4.Click the run button to execute the program
5.The lab equipment loans system will start and display its main menu
6.Follow the on screen instructions to borrow,return or check the availability of equipment
