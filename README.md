# UFP0007-M01123966
Option B-Lab equipment Loans
This program will manage recording equipment in the lab, lend equipment to students and record returned equipment

Purpose
1.The program will display a menu with different options
2.Users can view a list of available lab equipment
3.Users can select equipment they want to borrow
4.The system will record the equipment borrowed and update its availability
5.Users can return borrowed equipment
6.The system will update the equipment list when items are returned
7.Users can view what is currently available or borrowed 
the program will allow users to exit when they have finished

How to run
1.Clone Github repository onto your computer
2.Open the project folder in code editor
3.Locate main python program
4.Run the program using python
Follow the instructions displayed on the screen to borrow or return laboratory equipment
